# pi-copium

> something to smoke while you burn tokens.

pi package so I don't have to put typescript in my dotfiles. use it if you want, or don't. there are plenty of others out there.

## what is this?

a fancy working message line to stare at:

<img width="731" height="57" alt="Recording 2026-08-17 at 05 55 41" src="https://github.com/user-attachments/assets/b2de3094-1e74-4cbf-934a-565e0e361049" />

plus a hardcoded one-line footer: model, tokens, cost, turn, context, extension statuses.

## install

```bash
pi install git:github.com/scottmckendry/pi-copium
```

then `/reload` or restart pi.
