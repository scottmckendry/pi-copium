# pi-copium

> something to smoke while you burn tokens.

pi package so I don't have to put typescript in my dotfiles. use it if you want, or go support the creators the harness stole from.

## what is this?

a custom header to greet you when you start pi.

a fancy progress/status line to stare at. that's it.

mascot shamelessly "borrowed" from [pi-buddy](https://github.com/apat183/pi-buddy) by @apat183. shimmer effect and streaming word counter ported from [pi-topping](https://github.com/underactive/pi-topping) by @underactive. all credit to the original creators.

## install

```bash
pi install git:github.com/scottmckendry/pi-copium
```

then `/reload` or restart pi.
